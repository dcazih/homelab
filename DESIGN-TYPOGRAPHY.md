# Application titles

Use Plus Jakarta Sans ExtraBold (weight 800) for application names and titles in application headers. The source font and its license are in `Font/Plus_Jakarta_Sans/`. A reusable CSS definition and bundled font are in `profiles/assets/application-title.css` and `profiles/assets/plus-jakarta-sans-extrabold.ttf`. Apply the `application-title` class to the application name. Keep other text on the existing typography stack unless a later design calls for a change.

## Section headings

Use Sora for section and card headings (H2 and H3), retaining the existing sizes and weights. The supplied source is in `Font/Sora/`; the Bridge bundles a variable copy in `profiles/assets/sora.ttf`.
